# Phone codes

GeoGuessr trainer for regional phone area codes, one country at a time.
Live: https://tgm-hub.github.io/phone-codes/

- **Play**: a code appears, click its area on the map. Three levels: group only, group then code, or code directly (group given).
- **Explore**: study map with every code, search by code or city, notes on how each numbering system works.
- Interface in French and English.

Countries: Brazil (DDD), Japan (市外局番), Indonesia (305 codes on the 514 kabupaten/kota),
Philippines (37 codes, provinces), Thailand (22 codes, provinces), Turkey (82 codes, provinces),
Russia (89 codes, federal subjects), Poland (49 zones, rebuilt on powiats), Spain (province prefixes),
Peru (24 codes, departments), Colombia (60X zones, departments), South Africa (36 codes, rebuilt on
local municipalities), Malaysia (14 codes, districts), Australia (4 codes, states), New Zealand (5 codes, regions),
Romania (41 county codes), Ukraine (27 oblast codes), Croatia (20 county codes), France (5 zones, départements),
Germany (first digit 02-09, rebuilt on Kreise), Hungary (54 codes, rebuilt on járások), Greece (second digit 21-28, regions),
South Korea (17 codes, provinces and metropolitan cities), United States + Canada (427 area codes,
state/province level; also opens with #ca and #pr).
Next: Mexico, Argentina, Italy (need a district-level source). Chile has no geographic codes.

## How it works

Each country uses one of two rules (`match` in meta.json):

- `nearest` (Brazil, Japan): a code is anchored on its main city, and the answer is
  the code whose city is nearest to your click (Voronoi cells inside the group).
- `admin` (all the others): admin units list their own codes, so the answer is judged on
  the real code areas.

Levels: group (e.g. 0X), optional sub-block (`sub_len`, e.g. 0XY), then the code.

## Layout

```
index.html            app (no dependencies, loads data/<iso>.json on demand)
data/                 generated by build.py, do not edit
src/<iso>/meta.json   name, display format, groups, anchors, twins, tips (fr/en)
src/<iso>/codes.csv   code, group, city, local, admin, lat, lon, cities (";"-separated)
src/<iso>/admin.json  admin units: name, local, region, rings [[lon, lat], ...], codes, groups
build.py              validates src/ and writes data/
serve.cmd             local preview at http://localhost:8000 (PowerShell, no Python needed)
publish.cmd           build, preview, confirm, commit, push
```

## Adding a country

1. Create `src/<iso>/` with the three files above, or with `units.csv` + `anchors.csv` + `meta.json`
   and run `python tools/import_units.py <ISO> <geoBoundaries ADM file>` (see its docstring).
2. `python build.py` (errors block, warnings do not).
3. `serve.cmd` to check, then `publish.cmd`.

## Sources

Thailand, Turkey, Russia, Poland, Spain, Peru, Colombia, South Africa, Malaysia, Australia, New Zealand, Romania, Croatia, South Korea: codes from the English Wikipedia pages *Telephone numbers in
<country>* (read 2026-10-21). Russia: the 83 subjects of the geoBoundaries file (no annexed
territories). Poland: zones attached to powiats by nearest zone city, so borders are approximate.
South Africa: areas attached to local municipalities by nearest code town (town coordinates typed by hand),
so borders are approximate. Malaysia: Sarawak/Sabah division-to-district mapping typed by hand.
Australia and New Zealand follow states/regions; border-town exceptions are listed in the tips.
Ukraine: English Wikipedia *List of dialling codes in Ukraine* (Zakarpattia 031 and Rivne 036 were missing
from the fetched text and were added by hand). France: zones by département following the pre-2016 regions
(the Wikipedia pages give regions only). Germany: first-digit regions from the German Wikipedia
*Telefonvorwahl (Deutschland)*; Kreise attached to the nearest reference city (coordinates typed by hand).
Hungary: code towns from English Wikipedia; járások attached to the nearest code town, Budapest districts = 1.
Greece: second-digit regions per periphery (Wikipedia lists towns only); Attica accepts 21 and 22.
United States + Canada: area codes per state/province from English Wikipedia *List of North American
Numbering Plan area codes* (codes 200-858 read; 859-999 from the notes of that page and from
ravisorg/Area-Code-Geolocation-Database, which also gives the cities). The answer is the state or province.
Spain: 9xx prefixes only; Ceuta (956) and Melilla (952) are not in that table.
Boundaries: geoBoundaries gbOpen THA ADM1, TUR ADM1, RUS ADM1, POL ADM2, ESP ADM2, PER ADM1, COL ADM1, ZAF ADM3, MYS ADM2, AUS ADM1, NZL ADM1, ROU ADM1, UKR ADM1, HRV ADM1, FRA ADM2, DEU ADM3, HUN ADM2, GRC ADM2, KOR ADM1, USA ADM1, CAN ADM1, CC BY 3.0 IGO.

Philippines: codes per province from Wikipedia, *Telephone numbers in the Philippines*
(Davao Occidental, Davao de Oro and Dinagat Islands are not in its table and take the code of
the province they were split from); boundaries geoBoundaries gbOpen PHL ADM2, CC BY 3.0 IGO.

Indonesia: codes from [indonesia-kabupaten](https://github.com/TGM-hub/indonesia-kabupaten)
(Wikipedia); boundaries geoBoundaries gbOpen IDN ADM2, CC BY 3.0 IGO
(BPS - Statistics Indonesia, WFP, OCHA ROAP), simplified.

Brazil and Japan data come from the earlier trainers
[brasil-phone-code](https://github.com/TGM-hub/brasil-phone-code) and
[japan-phone-code](https://github.com/TGM-hub/japan-phone-code).
